Simulation software is built as an empty container that engineers fill with values collected from a few papers. Reify Technology builds KineticDraw to do that reading at scale and to keep the evidence attached to every number.

KineticDraw

KineticDraw reads hundreds of peer-reviewed papers per process. For each kinetic and physical parameter it retains the passage that reports the value, binds the value to the conditions it was measured under, and carries the published uncertainty through the process model. The user sees the range of values and where each came from, and decides which to build on.

  • Every value is traceable to the sentence or table row in the source that states it.
  • Every parameter is graded for how well it is supported, and the model reports which parameter limits its confidence.
  • The AI reads, extracts, and flags inputs that drift from the literature. The user ranks, optimizes, and sizes the design. A licensed engineer signs off.

Founders, processors, ports, and engineering firms can screen a process from the feedstock stream they have before commissioning a full design. The result is a graded model an engineer can interrogate and a founder can take to a lender.

Current development applies KineticDraw to converting forest residues into bioproducts, with three committed port sites in Washington State.
